# Contribuições

Preservar identidade UGC, JSON aninhado, strings vazias para desconhecidos e aparência sem idealização. Não impor câmera frontal, ruído, grão ou 8K como fatos universais.

Mudanças devem incluir motivo, caso de teste, resultado real quando alegado e changelog. Não incluir credenciais ou fotos privadas. Verificações estruturais não substituem análise visual e não devem ser anunciadas como equivalência ao agente original.
