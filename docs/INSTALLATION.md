# Instalação e atualização

Clonar `https://github.com/mxcapellani/BlackRoom-IA.git` ou baixar os arquivos. Copiar a pasta `.agents/skills/iphone-lofi-ugc-prompt/` para o local de descoberta do host. Preservar o nome técnico.

A análise requer visão e acesso real à imagem. A revisão textual pode funcionar sem nova imagem, mas não comprova fidelidade visual. Comparação visual exige ambas as referências. Geração final é etapa separada, sem execução automática.

Atualizar sem modificar o contrato padrão do JSON. Rever changelog, validar tipos e repetir testes visuais relevantes. Não introduzir valores de câmera ou resolução como fatos fixos de todas as imagens.
